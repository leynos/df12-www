Visual Design Assets

Rasterise every SVG in a design directory into PNG output with Inkscape. The manifest uses environment-backed variables, `foreach`, and a dedicated clean action without turning a small asset pipeline into a custom script.

Back to Examples Templating Guide

Directory Structure

visual-assets/
design/svg/
hero.svg
icon-grid.svg
build/raster/
Netsukefile

The example keeps the source tree readable: SVG assets stay under `design/svg/`, generated PNGs land in `build/raster/`, and the manifest carries both the conversion rule and the clean action.

Why it matters

Variable definitions are first-class. `inkscape` comes from the environment when needed, but the rest of the graph stays explicit and reproducible.

Annotated Manifest

docs/examples/visual_design.yml 
netsuke_version: "1.0.0"

vars:
  src_dir: design/svg
  out_dir: build/raster
  inkscape: "{{ env('INKSCAPE_BIN') | default('inkscape') }}"

rules:
  - name: rasterise
    command: "{{ inkscape }} --export-type=png --export-filename={{ outs }} {{ ins }}"
    description: "Rasterising {{ ins }}"
  - name: clean
    command: "rm -rf {{ out_dir }}"

targets:
  - foreach: glob(src_dir ~ '/*.svg')
    name: "{{ out_dir }}/{{ item | basename | replace('.svg', '.png') }}"
    rule: rasterise
    sources: "{{ item }}"

actions:
  - name: clean
    rule: clean

defaults:
  - "{{ out_dir }}/hero.png"
1

Environment-backed tools

`env('INKSCAPE_BIN')` keeps the command configurable without moving the rule out of the manifest.

2

Asset fan-out stays declarative

Every SVG becomes one PNG target. The filename rewrite happens in the templated `name` field, not in an opaque loop script.

3

Actions express operator tasks

Cleaning the output directory matters, but it is not a default target. Actions keep that distinction sharp.

Running the Build

Terminal
➜ ~/visual-assets netsuke build build/raster/hero.png
0.0s INFO Read `INKSCAPE_BIN` and resolved the default tool path.
0.1s INFO Expanded 12 SVG assets from `design/svg/`.
0.8s INFO [12/12] Rasterising `hero.svg` to `build/raster/hero.png`
Build complete: build/raster/hero.png

Build Flow

1. Resolve

Choose the Inkscape binary from the environment or fallback.

2. Discover

Match every `*.svg` input file.

3. Rasterise

Write one PNG output per asset.

4. Operate

Use the `clean` action when you want to reset the build directory.
